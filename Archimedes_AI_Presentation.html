How it works
Industry Reference Architecture — Whitespace Analysis
What it does
  • Fetches SAP-recommended products for the client's industry from the SAP Business Accelerator Hub (public OData API)
  • Compares reference products against both Baseline and Target LeanIX Excels
  • Shows gaps (whitespace) as a checklist — products recommended by SAP not yet covered
  • Adds selected products to the Target Excel with tag="Target Reference", lifecycle="plan"
  • Derives BC + ITC relations per product via Claude API and RBA catalog
Wizard — Step 8
  • Industry selector: 21 SAP industries (EC&O, Retail, Automotive, Utilities…)
  • Load button → fetches reference → shows gap list with checkboxes
  • Already covered products (Baseline or Target) clearly marked
  • Select all / individual checkbox → Apply → products written to Target Excel
  • Import order preserved: BC → App (with relApplicationToBusinessCapability + relApplicationToITComponent)

How it works
SAP Help Portal Contrast
What it does
  • After enrichment, optionally validates each RSA product mapping against help.sap.com
  • Searches official SAP documentation for each requirement's assigned product
  • Flags mappings with no direct documentation confirmation
  • Generates a help_contrast_report.json with per-requirement results
How to use
  • CLI: prompted automatically after Step 2 enrichment — answer s to activate
  • Wizard: checkbox appears after requirements are processed
  • Completely optional — pipeline continues either way
  • Results: ✓ Validated · ⚠ Review · — No RSA assigned

How it works
LeanIX API Enhancements
Reliability & Performance
  • Retry 429 with backoff — GraphQL calls auto-retry on rate-limit with exponential backoff (reads Retry-After header); also retries on network errors
  • Batch GraphQL (×20) — Fact sheet lookups use aliased multi-query calls (up to 20 per round-trip), reducing API calls from N to ⌈N/20⌉
  • ITComponent push — ITC sheet from Excel is now upserted into LeanIX before Applications (correct import order: BC → ITC → App → Initiative)
Catalog Intelligence & TO-BE Preview
  • ITC Catalog linking — ITComponents auto-linked to official LeanIX catalog entries (lx_ITC_XXXXXX) via /source/ltls/ API (mirrors existing App linking)
  • Enrich from catalog — After VERYHIGH match, copies hostingType and description from catalog fact sheet to workspace Application
  • Impacts API — Preview TO-BE — New wizard button calls POST /impacts/v1/projections: shows projected field changes for each Application given all active Transformations and a target date

How it works
RBA / RSA Catalogs — Always Up to Date
From Manual Export to Live API
  • Before: catalogs updated manually via Excel export from the SAP Value Experience Hub — error-prone, monthly at best
  • Now: one click in the wizard calls the MXP MCP server (SAP Model Experience Platform) and regenerates both JSONs in seconds
  • Auth: automatic via SAP SSO (I519409 identity) — no token to manage
  • Scope: dc676573 worksphere — SAP Reference Architecture
What Changed — May 2026
  • RBA: 1,141 BCs across 29 domains & 148 areas (was 756)
  • RSA: 515 SAP products across 16 domains (was 324)
  • Wizard Step 1 shows last-update age and a "Refresh from MXP" button — on-demand, not on every run
  • /update-catalogs Claude Code slash command for direct MCP-based refresh without a REST token
